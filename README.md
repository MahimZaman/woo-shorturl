# Woo ShortCart

Generates short links that add a WooCommerce product or variation to the cart and redirect the shopper to checkout.

## Installation

1. Place this directory at `wp-content/plugins/woo-shorturl/`.
2. Activate WooCommerce, then activate **Woo ShortCart**.

## Usage

Open **Create Short URL** in the short URL administration menu, select the product or variation and generate the link. Open it in a fresh shopping session to check the checkout destination.
